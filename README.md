# 🎯 Number Game Using Java

A simple **Number Guessing Game** developed using **Core Java**. The program generates a random number, and the player tries to guess the number with the help of hints provided by the program.

## 📌 Project Overview

The Number Game is a console-based Java application designed to practice fundamental Java programming concepts such as:

* Variables and data types
* Conditional statements
* Loops
* User input using `Scanner`
* Random number generation
* Methods
* Exception handling
* Basic Java programming logic

## 🎮 How the Game Works

1. The computer generates a random number.
2. The player enters a guessed number.
3. The program compares the guessed number with the generated number.
4. The player receives a hint:

   * **Too High** – The guessed number is greater than the target.
   * **Too Low** – The guessed number is smaller than the target.
   * **Correct** – The guessed number matches the target.
5. The game continues until the correct number is guessed.

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/PurnimaMungara/NumberGame-Java.git
```

### 2. Open the Project

Open the project in any Java IDE such as:

* IntelliJ IDEA
* Eclipse
* VS Code
* NetBeans

### 3. Compile the Program

```bash
javac NumberGame.java
```

### 4. Run the Program

```bash
java NumberGame
```
